# Nutrition Form Service

## 📌 Overview

The **Nutrition Form Service** is a microservice of the **NutriGym UCE Platform** designed to capture and manage nutritional information provided by students.
This data is later consumed by other microservices (such as the Meal Plan Generator and AI Recommendation Service) to generate personalized nutrition plans.

The service follows a **clean microservices architecture**, implements **JWT-based authentication**, and is built using **FastAPI**.

---

## 🚀 Features

* Secure JWT-based authentication (integrated with Auth Service)
* Capture and persist nutritional data per user
* Automatic association between user and nutrition form
* RESTful API with OpenAPI (Swagger) documentation
* Health check endpoint for monitoring
* Layered architecture (routes, services, models, schemas)
* Ready for asynchronous integrations (Kafka / Redis)

---

## 🧱 Tech Stack

* **Language:** Python 3.11
* **Framework:** FastAPI
* **Authentication:** JWT (Bearer Token)
* **ORM:** SQLAlchemy
* **Server:** Uvicorn
* **API Documentation:** OpenAPI 3.1 (Swagger UI)

## 🔐 Authentication

All protected endpoints require a **JWT Bearer Token** generated by the **Auth Service**.

The token must be included in the request header:

```http
Authorization: Bearer <JWT_TOKEN>
```

The service extracts the following claims from the token:

* `sub` → User ID
* `email`
* `role`

Role-based validation can be enforced at route or service level.

## 📡 API Endpoints

### ➤ Create Nutrition Form

**POST** `/nutrition-form`

Creates a nutrition form associated with the authenticated user.

#### Request Body

```json
{
  "meals_per_day": 5,
  "diet_type": "ketogenic",
  "allergies": ["peanuts", "shellfish"],
  "preferences": ["organic", "low_sodium"],
  "caloric_goal": 2500,
  "water_intake": 2000
}
```

#### Successful Response (200)

```json
{
  "id": "uuid",
  "user_id": "uuid",
  "meals_per_day": 5,
  "diet_type": "ketogenic",
  "allergies": ["peanuts", "shellfish"],
  "preferences": ["organic", "low_sodium"],
  "caloric_goal": 2500,
  "water_intake": 2000
}
```

